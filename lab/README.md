# 纸间寻迹｜档案修复实验室 V4.0

这是一个可直接在浏览器运行的静态网页项目，面向课堂汇报与现场互动展示。无需安装 Node、数据库或其他依赖。

## 文件结构

- `index.html`：网页入口
- `styles.css`：页面样式、投屏字号与响应式布局
- `app.js`：四份档案、步骤状态、拖放/点击交互、自动检查和修复记录
- `standards/`：网页中直接链接的规范 PDF 原文件

## 运行方式

1. 保持本文件夹（`lab/`）内 `index.html`、`styles.css`、`app.js`、`standards/` 的相对位置不变。
2. 不要单独移动 `index.html`；`standards` 文件夹里的 5 份规范 PDF 必须与网页在同一目录下。
3. 双击 `index.html`，使用 Chrome 或 Edge 打开。
4. 历史档案影像从故宫博物院网站加载，因此体验时需要联网。规范 PDF 已放在本项目的 `standards` 文件夹中，点击网页中的“打开 PDF”即可直接查看。

也可以将整个文件夹部署到 Vercel、Netlify 或其他静态网站托管服务。部署时请上传整个文件夹，不要漏掉 `standards/`。

## 与《档案里的木箱山河》的联动

本目录 `lab/` 位于故宫南迁互动叙事项目内，两个作品共用同一个站点域名，互相留有入口：

- 主项目 `../index.html`：开场页的「档案修复实验室」按钮、顶栏「史料 → 史料与说明」弹窗 → 进入本页。
- 本页 → 主项目：首屏「配套叙事体验」横条、页脚「返回《档案里的木箱山河》」。
- 全部使用相对路径，本地双击打开和线上部署都能跳转。

部署时必须把 `lab/` 整个目录**和主项目一起上传**。只传本页会导致返回链接失效；漏掉 `standards/` 会导致 5 份规范 PDF 打不开。

历史影像仍从 `img.dpm.org.cn` 远程加载（已实测无防盗链、国内可直连），因此体验时需要联网；样式表不再引用 Google Fonts，改用系统中文字体，避免国内首屏等待外部字体。

## 四份档案与不同互动

1. **驻沪办事处点验存沪文物规则草案**：补裂。拖放薄皮纸条对准裂口，再沿纸条进行局部施浆和排实。
2. **驻沪办事处点收存沪文物箱件总报告**：补缺。比较可见色卡，将独立补纸片拖入缺角，再用压纸板完成局部排实。
3. **欧阳道达呈马衡院长文**：纸浆补洞。七个孔洞位置固定，滴管点击附近即可识别；七处全部完成后，拖放吸水纸进行定形。
4. **蔡元培致马衡函**：局部加固。切换到网页绘制的背面操作示意，旋转加固纸使纤维方向匹配，再完成局部施浆与吸水压平。

补缺色卡支持拖到比较区，比较区会显示实际色块；工具卡支持直接拖向影像，也可以先点击拿起工具，再在影像上操作。正确与错误反馈显示在步骤面板内。未完成当前操作时不能进入下一步；只有最后一步完成后才能进行自动质量检查。

## 规范依据（网页链接到本地 PDF）

- `standards/GB-T-42468-1-2023.pdf`：GB/T 42468.1—2023《纸质档案抢救与修复规范 第1部分：破损等级的划分》
- `standards/GB-T-42468-2-2023.pdf`：GB/T 42468.2—2023《纸质档案抢救与修复规范 第2部分：档案保存状况的调查》
- `standards/GB-T-42468-3-2023.pdf`：GB/T 42468.3—2023《纸质档案抢救与修复规范 第3部分：修复质量要求》
- `standards/GB-Z-42468-4-2023.pdf`：GB/Z 42468.4—2023《纸质档案抢救与修复规范 第4部分：修复操作指南》
- `standards/DA-T-25-2022.pdf`：DA/T 25—2022《档案修裱技术规范》

## 历史影像来源

四份历史文书影像来自故宫博物院《文物南迁》专题“典守与保管”：

- https://www.dpm.org.cn/topic/move_south/keeping.html

图片使用前请遵循故宫博物院网站的版权与使用说明。网页不修改原始图片，病害与修复结果均通过 SVG 数字图层叠加。

## 专业边界说明

- 四份历史档案的名称与影像来源于故宫博物院专题；本网页叠加的撕裂、缺角、虫蛀孔洞和局部絮化均为**数字模拟病害**，不代表原件真实保存状况。
- 网页中的检测描述、材料匹配、操作轨迹和评分均为课堂互动情境，不是对历史原件进行的真实检测或修复。
- 补缺、补裂、纸浆补洞和局部加固的步骤说明，依据 DA/T 25—2022 相关条款及 GB/Z 42468.4—2023、GB/T 42468.3—2023 的相关要求整理为简化互动；不构成真实档案修复操作指导。
- 自动质量检查只判断网页中预设的互动条件，不等同于真实修复质量鉴定。
- 修复记录保存在当前浏览器的本地存储中；更换浏览器或清除站点数据后，记录可能无法保留。记录可另行下载。
