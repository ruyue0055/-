# V4.0 更新说明

本版不是在旧画布涂抹逻辑上增加按钮，而是移除自由涂色画布，改为按修复对象和操作类型判定。

- **补裂**：薄皮纸条拖放对位 → 排笔沿裂口施浆 → 棕刷沿线排实。
- **补缺**：可见色卡拖入比较区显示真实色块 → 独立缺角补纸片拖放吸附 → 压纸板局部排实。
- **纸浆补洞**：七个固定孔洞逐个识别 → 滴管逐孔填补 → 吸水纸覆盖定形。
- **局部加固**：切换到明确标注的背面操作示意 → 旋转加固纸匹配纤维方向 → 局部施浆 → 吸水压平。
- 工具卡采用自定义指针拖动，不再拖动整块工具栏；同时保留点击拿起工具的方式。
- 成功和错误结果显示在当前步骤下方；只有当前操作未完成时才弹出阻止继续的提示。
- 自动质量检查根据实际操作状态生成，不需要玩家勾选。
- 修复结果与操作记录可保存在当前浏览器，并可下载文本记录。
- 模拟病害、修复痕迹与背面示意均为网页 SVG 图层；原始影像不被修改。
- 五份规范 PDF 已随项目打包，网页直接链接到 `standards/` 中的文件。
